# The effects of Base in Bend 2.0.34, in the shape that `./bend base` prints
# them: a def whose body imports the effect's C and JavaScript files. IO.within
# is built on IO.sleep instead of importing files, so its body here is cut
# short. scripts/test-lint-lanes.sh feeds this excerpt to
# `scripts/lint-lanes.sh --base`, and scripts/validate.sh feeds the real
# output of the pinned compiler.
